# Studi Kasus 1: Analisis Kinerja Keuangan & Klasifikasi Risiko

Proyek ini disusun berdasarkan materi kuliah praktisi **"Make Sense of Data with Analysis and AI"** yang disampaikan oleh **Bapak Andria Arisal** (Badan Riset dan Inovasi Nasional - BRIN).

## Deskripsi Proyek
Proyek ini berfokus pada pengolahan dan analisis data keuangan perusahaan, melakukan pembersihan data (*data cleaning*), serta membangun model *Machine Learning* untuk mendeteksi dan mengidentifikasi risiko keterlambatan pembayaran (*late payment*).

## Pustaka & Teknologi yang Digunakan
- **Python**
- **Pandas** & **NumPy** (untuk manipulasi dan analisis data)
- **Scikit-Learn** (untuk pemodelan Machine Learning)
- **Matplotlib** (untuk visualisasi data)
